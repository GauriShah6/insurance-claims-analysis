Insurance Claims Analysis Using Python

Overview

This project analyses a fictional insurance portfolio using Python to understand claim frequency, claim severity, and total claim costs.

Objectives

- Calculate total claims and total claim costs.
- Analyse average claim severity.
- Calculate claims per policyholder.
- Visualise claim amounts using a bar chart.

Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Key Findings

- Policyholders analysed: 10
- Total number of claims: 15
- Total claim cost: ₹205,000
- Average claim severity: ₹13,666.67 per claim
- Claims per policyholder: 1.5

Conclusion

This beginner project demonstrates how Python can be used to summarise insurance claims data and calculate basic actuarial measures.

Disclaimer

The dataset is fictional and intended solely for educational purposes.
